# Experience / Memory Threat Model

Threats include issue/repository/tool prompt injection, fake verifier results,
paid-provider claims, DeepSeek reactivation, secrets, stale hashes,
contradictions and unbounded retrieval. Controls are schema validation,
provenance, trust classes, bounded retrieval, invalidation, deny-pattern
sanitization, no executable memory instructions and deterministic gates.

The memory bank is not a policy authority and cannot override n8n or the
existing provider/security contracts.
